# 🌿 HabitosEcoApp

HabitosEcoApp es una aplicación orientada a promover hábitos ecológicos y sostenibles en el día a día.  
El objetivo del proyecto es facilitar a los usuarios el seguimiento de actividades responsables con el medio ambiente, así como ofrecer información, motivación y herramientas para mejorar su impacto ecológico.

---

## 🚀 Funcionalidades previstas
- Registro de hábitos ecológicos (reciclaje, ahorro de agua, transporte sostenible, etc.)
- Sistema de seguimiento y estadísticas de progreso
- Recomendaciones personalizadas según el perfil del usuario
- Retos ecológicos diarios y semanales
- Interfaz intuitiva y accesible
